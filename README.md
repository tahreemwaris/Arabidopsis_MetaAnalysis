# Conserved Pan-Stress Transcriptomic Regulators in *Arabidopsis thaliana*

An automated, reproducible computational pipeline for multi-condition RNA-seq meta-analysis, cross-stress consensus DEG identification, functional enrichment, and protein interactome hub prioritization across 6 biotic and abiotic stress conditions.

## Stress Conditions Analyzed
* Heat Shock (37°C)
* Cold Stress (4°C)
* Drought / Dehydration
* Salinity (150 mM NaCl)
* Pseudomonas syringae pv. tomato DC3000
* Turnip Crinkle Virus (TCV)

## Repository Structure
- scripts/: Universal pipeline execution scripts
- results/figures/: High-resolution (300 DPI) publication figures
- results/tables/: Master hub gene tables and annotation metrics
